BOARD CONTROLS (matches current top.v)
   SW15..14 = 00 LOAD | 01 RUN | 10 VIEW | 11 VIEW
   SW13..8  = input ID during LOAD (6-bit)
   SW7..0   = input VALUE during LOAD (8-bit: 0..255)

   BTND = reset (CLEARS inputs and results)
   LED15..0 = current input preview in LOAD; selected value otherwise
   Seven-segment left digit = selected variable or FU.
   Rightmost three digits = decimal value.
   Values above 999 alternate with an H thousands page.
   LEDs show the full binary value.
